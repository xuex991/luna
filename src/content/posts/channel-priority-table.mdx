## 渠道优先级总表

| 优先级 | 渠道 | 主要职责 | 看什么 | 适合解决的问题 |
| --- | --- | --- | --- | --- |
| P0 | Upwork | 看真实市场成交 | 什么需求真的有人付钱、价格多少、需求是否重复出现 | 验证市场有没有钱 |
| P0 | X / Twitter | 看个人品牌与获客 | 别人怎么展示自己、怎么吸引客户、怎么包装 niche | 学会怎么把自己卖出去 |
| P1 | Reddit | 看行业真实讨论 | 哪些活赚钱、客户痛点、接单踩坑、市场情绪 | 判断市场情绪和真实痛点 |
| P1 | Discord | 看实时需求与圈子 | 小圈子合作、私单、AI automation 圈内需求 | 找即时合作和非公开机会 |
| P1 | Indie Hackers | 看小团队商业模式 | 一个人怎么长期赚钱、怎么转 recurring | 学商业模式，不只盯项目单 |
| P2 | GitHub | 看技术趋势与需求 | 哪些技术开始大量出现、哪些 repo 在吸客户 | 判断技术方向和潜在服务机会 |
| P2 | YouTube 小博主 | 看真实赚钱路径 | 一个人怎么从 0 到稳定接单 | 看路径，不是看大 V 鸡汤 |
| P3 | Dribbble | 看 UI 市场趋势 | 客户最近喜欢什么风格、哪些 SaaS 正流行 | 提升审美和包装能力 |

## 关键词维度

| 维度 | 作用 |
| --- | --- |
| 关键词 | 市场在说什么 |
| 需求类型 | 客户到底要解决什么 |
| 技术类型 | 涉及什么能力 |
| 客户类型 | 谁在付钱 |
| 成交强度 | 是否真的高频成交 |
| 客单价 | 大概多少钱 |
| 长期性 | 一次性还是 recurring |
| 竞争度 | 卷不卷 |
| AI 红利 | 是否吃 AI 趋势 |
